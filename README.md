# Prototype

## Структура проекта

```
index.html            разметка всех экранов
css/styles.css        весь дизайн: токены, темы регионов, адаптив
js/data.js            регионы и списки их заданий — весь контент
js/mascots.js         маскоты (SVG-заглушки, подмена PNG), иконки слов
js/storage.js         история прохождения (localStorage)
js/scoring.js         формула результата
js/core.js            навигация, таймер, прохождение заданий
js/exercises/         по файлу на тип задания: words, quiz, ornament, recipe
js/app.js             экраны: выбор культуры, результат, история
assets/               картинки
```
